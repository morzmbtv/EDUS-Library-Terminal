# EDUS · Библиотека — профиль целевого терминала

## Оборудование и среда

| Параметр | Значение |
| --- | --- |
| Экран | 10,1″ сенсорный |
| Базовое разрешение | 1280×800 px |
| Ориентация | Горизонтальная |
| Пропорции | 16:10 |
| ОС | Ubuntu |
| Браузер | Chromium в kiosk-режиме |
| Масштаб страницы | 100% |

1280×800 — основной проектный viewport. Референсные 1536×1024, 1600×900 и 1920×1080 остаются дополнительными размерами регрессии. Интерфейс не использует CSS `zoom`, `transform: scale` для всего приложения, фиксированный контейнер 1280px или `overflow: hidden` для сокрытия проблем геометрии.

## Геометрия и доступность

- Шапка: около 80px; нижняя панель действий: около 88px.
- Основная рабочая область: около 632px; внешние поля: 24px; рабочие промежутки: 16px.
- На экране выдачи после выбора читателя колонки занимают примерно 58% для сканирования и 42% для списка.
- Экранный заголовок: 30–34px; ФИО: 26–30px; основная инструкция: 24–28px; рабочий текст: 20–22px; вторичный текст: 18px; служебный: от 16px.
- Главные действия имеют высоту 64–72px; вспомогательные touch-зоны — минимум 56×56px.
- Длинные списки прокручиваются внутри панели, а читатель и главное действие остаются видимыми.

## Проверка

Целевой браузерный прогон: `node scripts/qa-kiosk-1280.mjs`. Он фиксирует `innerWidth`, `innerHeight` и `devicePixelRatio`, проверяет отсутствия прокрутки документа на главных экранах, внутреннюю прокрутку списка, ручной ввод с экранной клавиатурой, справку, подтверждение и ошибку. Физическая проверка пальцем на Ubuntu-терминале остаётся отдельным этапом после поставки устройства.
