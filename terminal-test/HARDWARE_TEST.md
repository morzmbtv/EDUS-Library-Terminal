# Проверка оборудования — EDUS Library Terminal TEST

Этот протокол проверяет готовый frontend на **реальном** терминале. Наличие этой инструкции не означает, что физические устройства уже проверены.

## Перед началом

1. Зафиксируйте Ubuntu version, browser version, разрешение CSS viewport, devicePixelRatio и модель терминала.
2. Убедитесь, что в Chrome включены JavaScript и localStorage для `http://127.0.0.1:43180`.
3. Запустите тестовый ярлык. В шапке должен быть виден бейдж **«Тестовый режим»**.
4. В шестерёнке откройте **«Панель тестирования»**. Панель по умолчанию закрыта.
5. Запишите результат `scripts/diagnose-terminal-test.sh`. Отсутствие сети не должно блокировать локальный сценарий.

## Карта / NFC или keyboard wedge

1. На главной откройте «Выдать книги».
2. В панели тестирования выберите читателя, нажмите «Ожидать карту», приложите карту или отправьте её raw-код устройством. Ввод должен появиться только в режиме ожидания и завершиться Enter.
3. Подтвердите локальную привязку. Вернитесь на идентификацию и повторите ввод карты: должен появиться выбранный читатель.
4. Повторите для «Принять книги». Проверьте ручной поиск как резервный путь.

## Сканер книг

1. В выдаче выберите читателя. В панели выберите «Конкретный экземпляр», нажмите «Ожидать сканер», отсканируйте код и привяжите его локально.
2. Отсканируйте тот же код в рабочем экране: в корзине должен появиться только этот экземпляр.
3. Для ISBN выберите «Издание по ISBN». Убедитесь, что ISBN не выбирает случайный экземпляр или владельца.
4. Выполните полный цикл: **выдача → подтверждение → приём тем же читателем → подтверждение**.
5. Проверьте чужую книгу, повторный scan, неизвестный код, задержку и ошибку следующей операции. Не должно быть ложного успеха.

## Persistence / touch

1. Отметьте или выдайте книгу, закройте Chrome, запустите ярлык снова. Состояние тестовых данных должно сохраниться.
2. Откройте панель, подтвердите «Сбросить тестовые данные». Сбрасываются только данные тестового профиля.
3. Пройдите элементы пальцем: шапка, «?», ручной поиск, «Назад», смена читателя, нижнее подтверждение и прокрутка длинного списка.
4. Проверьте 1280×800 без горизонтальной прокрутки и обрезанных основных кнопок.

## Критерии остановки

Остановите UAT и приложите вывод диагностики, если: карта/сканер вводит данные вне режима захвата, localStorage недоступен, терминал показывает ложный успех, service health не принадлежит пакету, порт занят другим процессом или появляется запрос к внешнему/школьному API.
