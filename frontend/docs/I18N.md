# RU / KK

One existing `t()` localization function, reactive `locale`, dictionaries in `i18n.ts` and `translations.kk.json`. UI literals are translated; reader names, titles, authors, ISBN, scanner codes and API values are never translated.

Locale is loaded and written through `/settings/ui`, so it survives a new Edge InPrivate session. A failed save is visible. Language changes do not reset the workflow, query or basket. Keyboard layout is a separate transient UI choice; Kazakh rows contain Ә Ғ Қ Ң Ө Ұ Ү Һ І and lowercase forms.

Date formatting uses `ru-RU` / `kk-KZ`. Technical errors with unknown codes retain a safe fallback; no machine translation, CDN or online language service is used. Human review of Kazakh phrasing and physical touch layout remains part of terminal UAT.
