# Microsoft Edge Assigned Access — внешняя настройка Windows

EDUS не создаёт Windows-пользователей, не включает Assigned Access, Shell Launcher, AppLocker или Keyboard Filter. Управление киоском выполняется средствами Windows вне EDUS. Служба и конфигуратор не выбираются в списке приложений киоска: выбирается **Microsoft Edge**.

## Предварительная проверка

На физическом терминале получите версию, редакцию и сборку через `winver` и «Параметры → Система → О системе». Характеристики development PC не подтверждают поддержку терминала. Assigned Access доступен не во всех редакциях Windows; поддержку и названия меню сверяйте с [официальной документацией Microsoft](https://learn.microsoft.com/en-us/windows/configuration/assigned-access/).

Сначала установите ZIP по QUICK_START_RU.md, создайте UAT/Production через конфигуратор, выполните Verify-EDUS.ps1. Под обычным Windows-пользователем проверьте `http://127.0.0.1:43180` и `http://127.0.0.1:43180/health`. Не открывайте доступ пользователя к ProgramData: Edge получает данные только через API.

## Настройка администратором

1. Windows 11: «Параметры → Учётные записи → Другие пользователи → Настройка киоска». Windows 10: «Учётные записи → Семья и другие пользователи → Настройка киоска». Формулировки зависят от сборки.
2. Создайте/выберите отдельного стандартного пользователя киоска.
3. Выберите **Microsoft Edge**.
4. Выберите режим **Digital/Interactive signage** (цифровой/интерактивный информационный экран).
5. Укажите `http://127.0.0.1:43180`.
6. Выберите подходящий интервал перезапуска браузера. Завершите настройку и перезагрузите выделенный терминал.
7. Проверьте вход, открытие Edge, выдачу/приём без интернета, перезапуск браузера, сохранение RU/KK и восстановление связи после перезапуска службы.

[Microsoft: настройка Edge kiosk](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-configure-kiosk-mode). InPrivate не является хранилищем EDUS: библиотечные данные и язык сохраняет служба.

Если Edge открылся до появления listener, Vue ещё не загружен и его retry не работает. Перезагрузите страницу после готовности службы; фактический порядок запуска при reboot обязательно проверить на терминале. После загрузки UI клиент восстанавливает HTTP-session/SSE. Не считать эту проверку выполненной по одному автоматическому запуску службы.

## Камера

Администратор может настроить [VideoCaptureAllowedUrls](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-browser-policies/videocaptureallowedurls) только для `http://127.0.0.1:43180`, совместно с политикой [VideoCaptureAllowed](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-browser-policies/videocaptureallowed). Не разрешайте камеру всем сайтам. Скрипты EDUS эти политики не применяют. Production Face без утверждённого провайдера/PAD остаётся недоступен; доступ к камере не означает готовность распознавания.

## Физический UAT

Проверить: autologon, полноэкранный Edge, touch 1280×800, настоящую карту/сканер с Enter/Tab, камеру, отключённую сеть, перезапуск службы, reboot, предусмотренный Windows выход Ctrl+Alt+Delete, пароль административного входа и возврат в киоск. Сохраните отдельно доступ администратора Windows и согласованный recovery-порядок.

Фактическая редакция/build терминала в этой сборочной сессии не проверена. **PHYSICAL ASSIGNED ACCESS: NOT EXECUTED.**
