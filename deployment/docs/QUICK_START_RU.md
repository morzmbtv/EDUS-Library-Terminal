# EDUS Library — один переносимый ZIP

Версия 2.0.0-rc.1, UNSIGNED RC/UAT. Frontend и Backend остаются отдельными исходными проектами, поставка одна: `EDUS-Library-Portable-2.0.0-rc1.zip`. Это переносимый комплект установки Windows-службы; после распаковки требуется одна административная настройка.

## Что требуется

Windows x64, установленный Microsoft Edge, Windows PowerShell 5.1 x64 и права администратора. Node, npm, Rust, Cargo, MSVC, Python, Docker и Laravel на терминале не нужны. Интернет для локального UAT не нужен. Архив содержит официальные app-local VC Runtime DLL; скачивания runtime при установке нет.

## Установка

1. Перенесите ZIP на терминал. Сверьте SHA-256 с опубликованным вместе с релизом значением. Распакуйте **весь** архив; рядом должны остаться `backend`, `frontend`, `scripts`, `docs`, `deployment.json`, `manifest.json`.
2. Откройте **Windows PowerShell от имени администратора**, перейдите в распакованную папку `EDUS-Library`. Не запускайте скрипт из окна просмотра ZIP.
3. Выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\Setup-EDUS.ps1
.\scripts\Verify-EDUS.ps1
```

Разрешение ExecutionPolicy действует только в текущем процессе PowerShell. Оно не заменяет проверку происхождения архива. Хеши внутри неподписанного архива обнаруживают повреждение, но не удостоверяют издателя.

Скрипт копирует программу в `%ProgramFiles%\EDUS Library`, проверяет принадлежность существующей службы, устанавливает/обновляет `EDUSLibraryService`, настраивает LocalService, service SID, автоматический запуск и восстановление. Данные находятся отдельно в `%ProgramData%\EDUS Library`. Диск E: на терминале не требуется. Windows Assigned Access автоматически не включается.

## Первый UAT без Cloud

1. В меню «Пуск» запустите **EDUS Terminal Configurator**, подтвердите UAC. Это обычный установленный EXE, второго установщика нет.
2. Выберите UAT и создайте тестовый workspace/seed. До настройки `SETUP_REQUIRED` является ожидаемым состоянием новой установки.
3. В конфигураторе добавьте вымышленного читателя, привяжите карту в явном режиме захвата; добавьте книги и привяжите сканерные коды. Не вводите реальные персональные данные в UAT.
4. Откройте `http://127.0.0.1:43180/health`, затем `http://127.0.0.1:43180` в Edge. После настройки рабочего пространства ожидается `READY`.
5. Проверьте карту → выдачу → изменение наличия в поиске → приём. Проверьте повторное определение карты после перезапуска службы.
6. Для Production используйте существующий enrollment в конфигураторе: Cloud URL, код подключения, имя терминала. UAT не переключается в Production автоматически.

Обычный Edge-интерфейс содержит язык RU/KK, справку, версию и безопасный статус. Административные действия выполняются через конфигуратор и защищённый named pipe.

## Повторная установка и восстановление

Распакуйте новый полный архив отдельно и запустите `Setup-EDUS.ps1` повторно либо:

```powershell
.\scripts\Repair-EDUS.ps1
.\scripts\Verify-EDUS.ps1
```

Не удаляйте БД, WAL/SHM, `secrets.dpapi`, конфигурацию или резервные копии для «исправления» установки. При чужой/неоднозначной службе, занятом порте или повреждённом пакете установка отказывает с диагностикой. Не завершайте неизвестный процесс на порте 43180. Журналы запусков сохраняются раздельно; путь показывается скриптом.

Предыдущие бинарники сохраняются на случай восстановления. Автоматического отката схемы БД нет: после запуска новой версии нельзя считать старые бинарники совместимыми с новой схемой без проверки. Существующую per-user Tauri DB не копируйте вместо service DB: ключи принадлежат разным Windows-контекстам. Неподдерживаемая миграция отказывает без удаления источника.

## Удаление

```powershell
.\scripts\Remove-EDUS.ps1
```

По умолчанию удаляются служба и файлы приложения, `%ProgramData%\EDUS Library` сохраняется. `-RemoveData` допустим только после отдельного явного подтверждения удаления данных; это необратимая операция. Архив и старый Tauri rollback автоматически не удаляются.

## Статус проверки

Смотрите `ACCEPTANCE.md`: сборка, проверка содержимого и локальный console-runtime не доказывают установку под SCM/LocalService. До испытания на разрешённой Windows-машине установка имеет статус **INSTALLATION NOT VERIFIED**. Физическая карта, сканер, камера, touch, Assigned Access и перезагрузка требуют проверки на терминале.
