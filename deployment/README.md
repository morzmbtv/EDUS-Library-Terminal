# EDUS Library portable deployment 2.0.0-rc.1

Release assembly only. Vue source remains in the independent frontend repository; Rust source remains in the independent backend repository. Cloud is not included.

Run `pwsh -File build-edus-portable.ps1` on the development host. The pipeline runs frontend and Rust checks/builds, collects native binaries and official app-local VC runtime DLLs, generates hashes, validates the staged package, creates one ZIP and re-extracts/revalidates it. No NSIS or MSI is invoked.

Delivery: `E:\Codex\artifacts\EDUS-Library-Portable-2.0.0-rc1.zip`, one root directory `EDUS-Library`. Target requires Windows x64, installed Microsoft Edge and administrator PowerShell for deployment. No build toolchain is required there.

Runtime entry scripts are under `scripts/`; they do not enable Assigned Access. Production/UAT databases and DPAPI keys are generated by the service in its stable LocalService context, not distributed in the package.

See `docs/QUICK_START_RU.md`, `docs/EDGE_KIOSK_SETUP_RU.md`, and `docs/ACCEPTANCE.md`. Source/parser/filesystem tests must not be presented as SCM/ACL clean-install acceptance.
